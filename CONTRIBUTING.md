# Contribuindo

Obrigado pelo interesse na Maia.

Durante a beta, use Issues para relatar bugs ou sugerir recursos. Antes de enviar:

1. verifique se já existe uma issue semelhante;
2. teste na versão mais recente;
3. remova tokens, nomes pessoais e endereços privados;
4. descreva um problema por issue.

Pull requests devem explicar o motivo da mudança, os arquivos afetados e os testes executados. Alterações de interface devem incluir uma captura de tela.

Ao contribuir, você confirma que possui direito de enviar o conteúdo. A aceitação de uma contribuição não altera a licença proprietária do projeto.
