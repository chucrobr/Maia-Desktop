# Segurança

## Como informar uma falha

Não publique tokens, chaves, endereços privados ou dados pessoais em uma issue.

Para uma falha que possa expor dados ou permitir ações sem autorização, entre em contato diretamente com **@clchucro** pelo Instagram:

https://www.instagram.com/clchucro/

Inclua a versão afetada, uma descrição curta e os passos necessários para reproduzir. Envie capturas somente depois de ocultar informações privadas.

## Versões atendidas

Durante a beta, apenas a versão mais recente recebe correções.

## Credenciais

O projeto não distribui credenciais pessoais. Cada usuário deve configurar e proteger seus próprios tokens de Home Assistant, Google Routes, Spotify, Arkama/Netlify e demais serviços.
